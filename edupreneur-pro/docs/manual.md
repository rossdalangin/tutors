# EdupreneurPro User Manual

## Introduction
EdupreneurPro is your all-in-one solution for building a successful education business on WordPress. This manual covers everything from installation to managing your students.

## 1. Installation
1. Upload the `edupreneur-pro` folder to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Custom database tables will be created automatically upon activation.

## 2. Setting Up Your First Course
1. Go to **EdupreneurPro > Courses**.
2. Click 'Add New Course'.
3. Enter course details (Title, Description, Price).
4. Use the Course Builder to add Modules and Lessons.
5. Publish your course to make it available to students.

## 3. Managing Payments
1. Ensure your payment gateway (Stripe/PayPal) is configured.
2. All orders can be tracked under the **Business Dashboard**.

## 4. Community Engagement
- Each course has a private discussion board.
- Students can interact with each other and the tutor.
- Use the **Community** settings to moderate posts.

## 5. Affiliate Program
- Enable the **Affiliate Engine** to allow others to promote your courses.
- Affiliates get a unique referral link and dashboard.
- Commissions are calculated automatically based on your set rate.

## 6. Troubleshooting
- If the CSS doesn't load, ensure your server permissions allow access to the `/assets/` directory.
- For REST API issues, verify that your Permalinks are set to something other than 'Plain'.
