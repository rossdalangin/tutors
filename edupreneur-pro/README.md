# EdupreneurPro - Senior Senior senior senior Educator Business OS

EdupreneurPro is a production-grade WordPress plugin designed for educators to operate as full-scale education businesses. It features a modular architecture, comprehensive course building, integrated payments, community engagement, and a powerful affiliate engine.

## 🚀 Key Features
- **3-Tier Course Builder**: Course → Module → Lesson drag-and-drop hierarchy.
- **Advanced Monetization**: Pluggable gateways (Stripe, PayPal, GCash) with subscriptions and bundles.
- **Affiliate Marketing**: Full referral tracking with anti-fraud and commission overrides.
- **Community OS**: Private discussion boards and secure direct messaging.
- **Business Dashboard**: Detailed analytics for revenue, student progress, and performance.

## 🛠 Installation
1. Upload the `edupreneur-pro` folder to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **EdupreneurPro → Settings & Tools** and click **Load Sample Data** to get started instantly.
